# EzLib Docs (GitHub Pages)

Public static docs for [ezlib.ykyle.eu](https://ezlib.ykyle.eu/).

## Language & version

Top-right controls:

| Control | Default | Notes |
| --- | --- | --- |
| **Lang** | 中文 (`/`) | English = [`/en.html`](https://ezlib.ykyle.eu/en.html) |
| **Version** | **2.0.2** | Same-page panes (`only-v200` / `only-v201` / `only-v202` / `since-v201`); `?v=2.0.1` / `?v=2.0.0` deep-links |

Lang switch keeps the current Version and `#hash`. Compat paths `/2.0.1/` and `/2.0.2/` redirect into the single-page docs.

## Files

| File | Role |
| --- | --- |
| `index.html` | Chinese docs |
| `en.html` | English docs |
| `style.css` / `script.js` | Shared UI, version panes, bilingual quiz |
| `2.0.1/index.html` | Compat redirect → `/?v=2.0.1` |
| `2.0.2/index.html` | Compat redirect → `/` (2.0.2 default) |
| `CNAME` | `ezlib.ykyle.eu` |

Do not change the in-page download zip URL when editing docs.
