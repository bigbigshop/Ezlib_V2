# EzLib 說明書（GitHub Pages）

本倉庫是 [ezlib.ykyle.eu](https://ezlib.ykyle.eu/) 的公開靜態說明書。

**同一個 `index.html`**，右上角 **Version** 即時切換內容（唔使換頁）：

| Version | 預設？ | 內容重點 |
| --- | --- | --- |
| **2.0.0** | ✅ 是（打開網站就係呢個） | 底盤、auton、Dash、PID 調校 |
| **2.0.1** | 右上角揀，或 `/?v=2.0.1` | 升降臂入門、Brain CONSOLE 印字、多例子 |

舊連結 [`/2.0.1/`](https://ezlib.ykyle.eu/2.0.1/) 會自動轉去 `/?v=2.0.1`。

細節以 [EzLib-EzDrive-motions](https://github.com/bigbigshop/EzLib-EzDrive-motions) 對應 branch 為準。
